```text

```

发送 `0x320`（含正确 mask）后期望：`ros_id` / `parsed` / `enq` / **`applied` 同步增长**，不能只有 `enq`。

```text
rehab assist 5
# 或语音：切换助力模式
cmd_motor_fb 5
```

期望：受限电流非零、fault 可解释、不反关节失控；穿戴测试前先无负载确认方向。
